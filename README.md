Atuo principalmente no desenvolvimento de aplicações **Android**, sistemas **web e backend**, automações e integrações entre plataformas.

## 🚀 Projetos em destaque

### 📺 SquiTV — Android TV

[![SquiTV](https://img.shields.io/badge/Ver_Projeto-SquiTV-2563EB?style=for-the-badge&logo=android&logoColor=white)](https://github.com/Rafael020703/SquiTV)

Aplicativo desenvolvido para **Android TV**, com foco em navegação fluida, experiência moderna e reprodução de conteúdo.

**Principais tecnologias e recursos:**
- Kotlin, Coroutines e Flow
- Jetpack Compose e Material 3
- Clean Architecture e MVVM
- Media3 / ExoPlayer
- Dagger Hilt, Room e DataStore
- Retrofit, OkHttp e APIs
- Navegação por controle remoto (D-pad)
- Pareamento de dispositivos pela rede local

`Kotlin` `Android TV` `Jetpack Compose` `MVVM` `Media3`

### 🎬 SODORAFA — Streaming & Automation

[![SODORAFA](https://img.shields.io/badge/Ver_Projeto-SODORAFA-2563EB?style=for-the-badge&logo=twitch&logoColor=white)](https://github.com/Rafael020703/SODORAFA)

Sistema de overlays, automação de chat e monitoramento para criadores de conteúdo.

**Principais recursos:**
- Overlays interativos para transmissões
- Reprodução de clipes em tempo real
- Integração com Twitch e Discord
- Autenticação OAuth
- Dashboard e painel administrativo
- Comandos automatizados para chat
- Monitoramento e notificações

`JavaScript` `Node.js` `Express` `Socket.IO` `Twitch API`
